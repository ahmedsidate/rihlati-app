# حسابات رحلتي

تطبيق محاسبة لوكالة السفر والحج والعمرة. يعمل في المتصفح ويُثبَّت على الهاتف (PWA)، **ويعمل دون إنترنت**، ثم يزامن بياناته مع Supabase عند عودة الاتصال.

## الملفات
- `index.html` — التطبيق كاملاً.
- `shim.js` — التخزين المحلي (IndexedDB) + المزامنة مع Supabase + الدخول (رمز/رابط البريد) + إدارة الموظفين.
- `sw.js` — Service Worker لتخزين التطبيق للعمل دون اتصال.
- `manifest.webmanifest` والأيقونات — للتثبيت على الشاشة الرئيسية.

## قاعدة البيانات (Supabase)
- `rh_staff`: بريد الموظف + الدور (`admin` / `employee` / `readonly`). من ليس فيها لا يرى شيئاً.
- `rh_docs`: كل السجلات (عملاء، حجوزات، سندات…) كوثائق JSON مع رقم تسلسلي للمزامنة.
- `rh_files`: مرفقات المسافرين (مقاطع base64).
- الصلاحيات عبر RLS: الموظف يكتب ولا يعدّل الإعدادات، والقراءة فقط لا يكتب، والمدير وحده يرى سجل التدقيق.

## المزامنة
- كل تعديل يُحفظ محلياً أولاً ثم يُرفع عند توفر الإنترنت.
- التعارض على السجل نفسه: آخر تعديل يغلب.
- أول فتح على جهاز جديد يحتاج إنترنت لتنزيل البيانات.

## إعدادات Supabase المطلوبة (مرة واحدة)
1. Authentication ← URL Configuration: ضع `Site URL` و`Redirect URLs` برابط التطبيق.
2. (اختياري) Authentication ← Email Templates (Confirm signup وMagic link): أضف `<p>رمز الدخول: {{ .Token }}</p>` ليصل رمز من 6 أرقام. بدونه يمكن الدخول بنسخ رابط الرسالة ولصقه في خانة الدخول بالتطبيق.
